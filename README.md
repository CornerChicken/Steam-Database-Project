README edited by Joseph Tse

This project was made in collaboration with 3 other members, in which we explored different ways different statistics may affect steam game popularity. In specific, we look at price, rating, recommendations, and other statistics to help reach a conclusion on what makes a game "good". 

We use Python and VS Code to help create this report, and found multiple different databases online of steam games and their analytics. This required manipulating the strings and .csv files given to us to organize all of the data and be able to grab tangible information for us to read.
